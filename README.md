# SIMQUIN

**SIMQUIN** adalah aplikasi berbasis web untuk manajemen quotation dan invoice.  
Dibangun menggunakan **PHP Native** dengan database **MySQL**.

---

## 🚀 Fitur Utama

- Manajemen Produk
- Manajemen User
- Manajemen Quotation / Penawaran
- Manajemen Invoice
- Template untuk pengembangan lebih lanjut

---

## 🛠️ Teknologi yang Digunakan

- [PHP 7.4+](https://www.php.net/)
- [MySQL/MariaDB](https://www.mysql.com/)
- [XAMPP](https://www.apachefriends.org/)
- [Bootstrap](https://getbootstrap.com/)
- [jQuery](https://jquery.com/)

---

## 📦 Instalasi

1. Clone repo ini ke dalam folder `htdocs` XAMPP:

   git clone https://github.com/iamchaeril/SIMQUIN.git
